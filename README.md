# Pan-Pathology Ontology

An interactive working draft of a pan-pathology ontology designed to support standardized labeling of whole-slide image datasets.

[Explore the interactive ontology](https://sjfish3.github.io/ontmerge/)

## Overview

Pathology concepts are described differently across reference sources, organ systems, and external terminologies. This project integrates these resources into a shared hierarchical structure while preserving diagnostic distinctions, organ context, synonyms, source provenance, and terminology mappings.

The ontology currently includes:

- 12 organ systems
- 71 organs and anatomic sites
- More than 5,000 concepts
- WHO Classification of Tumours and Pathology Outlines source information
- ICD-O, ICD-10/11, and NCIt mappings where available

Ten female genital tract sites have completed a second curation pass. Other organ systems remain working drafts undergoing iterative review.

## Interactive browser

The browser provides:

- Expandable organ-system and diagnostic hierarchies
- Concept search
- Preferred labels and synonyms
- Organ and site context
- Source provenance
- External terminology mappings
- Review and curation information

## Project status

This resource is an evolving research ontology. It has not been fully expert-reviewed or clinically validated and should not be used for clinical diagnosis or patient care.
